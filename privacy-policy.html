쿠팡 통합 도우미 - 개인정보 처리방침

최종 업데이트: 2025년 11월 9일

📌 핵심 요약: 이 확장 프로그램은 어떠한 개인정보도 수집, 저장, 전송하지 않습니다. 모든 데이터는 사용자의 기기(브라우저)에서만 처리됩니다.

1. 서비스 개요

"쿠팡 통합 도우미"는 Chrome 확장 프로그램으로, 쿠팡 쇼핑몰에서 리뷰 작성을 돕고 상품 페이지 간 편리한 이동을 제공하는 생산성 도구입니다.

2. 개인정보 수집 및 이용

2.1 개인정보 수집 여부

이 확장 프로그램은 개인정보를 수집하지 않습니다.

  • ❌ 이름, 이메일, 전화번호 등 개인 식별 정보 수집 안 함
  • ❌ IP 주소, 위치 정보 수집 안 함
  • ❌ 쿠팡 계정 정보 수집 안 함
  • ❌ 결제 정보, 주문 내역 수집 안 함
  • ❌ 사용자 행동 추적 안 함 (Analytics 미사용)

2.2 로컬 저장 데이터 (Chrome Storage API)

다음 설정값만 사용자의 브라우저에 로컬로 저장됩니다 (서버 전송 안 됨):

  • 리뷰 스타일 설정 (반말/존댓말)
  • 리뷰 글자 수 설정 (50-2000자)
  • 베스트 리뷰 모드 활성화 여부

이 데이터는 사용자의 기기에만 저장되며, 외부로 전송되지 않습니다.

3. 외부 서버 통신

3.1 Cloudflare Workers 프록시 서버

AI 리뷰 생성 기능 사용 시, 안전한 API 통신을 위해 Cloudflare Workers 프록시 서버 (coupang-gemini-proxy.hvnvit.workers.dev)와 통신합니다.

3.2 전송되는 데이터

  • 수집된 리뷰 텍스트: 쿠팡 상품 페이지에서 공개된 리뷰만 전송
  • 프롬프트 설정: 사용자가 선택한 글자 수, 스타일 등
  • 익명 사용 통계: 중복 리뷰 방지를 위한 임시 해시값 (개인 식별 불가)

3.3 전송되지 않는 데이터

  • ❌ 쿠팡 계정 정보 (이름, 이메일, 주소 등)
  • ❌ 결제 정보, 신용카드 정보
  • ❌ 주문 내역, 구매 이력
  • ❌ 개인 식별 가능한 정보

3.4 Google Gemini API

리뷰 생성을 위해 Google Gemini API를 사용하며, API 통신은 Cloudflare Workers를 경유합니다. Google의 개인정보 처리방침은 여기에서 확인하세요.

4. 쿠키 및 추적 기술

이 확장 프로그램은 쿠키, 추적 픽셀, 분석 도구를 사용하지 않습니다.

5. 권한 사용 목적

5.1 activeTab

  • 용도: 현재 열린 쿠팡 탭에서 리뷰 내용 읽기
  • 범위: 사용자가 확장 프로그램 아이콘 클릭 시에만 작동

5.2 storage

  • 용도: 사용자 설정값 저장 (반말/존댓말, 글자 수 등)
  • 범위: 로컬 브라우저에만 저장, 서버 전송 안 됨

5.3 tabs

  • 용도: 리뷰 페이지 ↔ 상품 페이지 간 이동
  • 범위: 쿠팡 사이트 내에서만 작동

5.4 scripting

  • 용도: 리뷰 페이지에 "상품 보기" 버튼 추가
  • 범위: my.coupang.com/productreview/* 페이지에만 적용

5.5 Host Permissions (coupang.com)

  • 용도: 쿠팡 사이트에서만 확장 프로그램 작동
  • 범위: www.coupang.com, m.coupang.com, my.coupang.com

6. 데이터 보안

  • ✅ HTTPS 암호화 통신
  • ✅ API 키는 서버에서 관리 (클라이언트에 노출 안 됨)
  • ✅ 개인정보 미수집으로 유출 위험 없음
  • ✅ 로컬 저장 데이터는 Chrome의 보안 정책에 따라 보호

7. 제3자 공유

이 확장 프로그램은 어떠한 데이터도 제3자와 공유하지 않습니다. Google Gemini API와의 통신만 이루어지며, 이는 리뷰 생성을 위한 목적으로만 사용됩니다.

8. 아동의 개인정보 보호

이 서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 의도적으로 아동의 개인정보를 수집하지 않습니다.

9. 사용자 권리

9.1 설정 삭제

사용자는 언제든지 저장된 설정을 삭제할 수 있습니다:

  • Chrome 확장 프로그램 삭제 시 모든 로컬 데이터 자동 삭제
  • Chrome 설정 → 개인정보 및 보안 → 인터넷 사용 기록 삭제

9.2 확장 프로그램 제거

언제든지 Chrome 확장 프로그램 관리 페이지에서 제거할 수 있습니다:

  1. chrome://extensions/ 접속
  2. "쿠팡 통합 도우미" 찾기
  3. "제거" 버튼 클릭

10. 개인정보 처리방침 변경

이 방침은 필요에 따라 변경될 수 있으며, 중요한 변경 사항은 확장 프로그램 업데이트를 통해 공지합니다.
